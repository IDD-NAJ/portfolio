# Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and experience.

## Features

- Responsive design for all devices
- Dark/Light mode toggle
- Interactive sections for projects, skills, and experience
- Contact form with email integration
- Smooth animations and transitions
- PDF resume download
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts

## Setup

1. Clone the repository:
```bash
git clone https://github.com/IDD-NAJ/portfolio.git
```

2. Open `index.html` in your browser to view the website locally.

## Deployment

The website is deployed using GitHub Pages. Visit: [https://idd-naj.github.io/portfolio/](https://idd-naj.github.io/portfolio/)
